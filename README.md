# RentPin

The website for [RentPin](https://devrashed01.github.io/rentpin/), a private map of the to-let gates you photograph. Android downloads are on the [releases page](https://github.com/devrashed01/rentpin/releases).

- [Privacy policy](https://devrashed01.github.io/rentpin/privacy.html)
- [Community rules and terms](https://devrashed01.github.io/rentpin/terms.html)
